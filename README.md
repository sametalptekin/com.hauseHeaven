# HH QA | Automation & Manual Testing Project

This project was developed as part of the Wise Quarter SDET training program and focuses on end-to-end Quality Assurance processes for the real estate platform [qa.hauseheaven.com](https://qa.hauseheaven.com).

## 🔰 Project Overview

The purpose of this project is to simulate a real-world QA environment by applying both **manual** and **automation testing** methodologies within a Scrum-based team structure.

As the **Team Lead**, I was responsible for organizing sprints, coordinating team collaboration, assigning tasks, and maintaining efficient communication throughout the development cycle.

---

## 🧪 Manual Testing

- Prepared detailed test cases and scenarios based on realistic user stories.
- Executed tests across multiple browsers and devices.
- Reported and tracked bugs using issue tracking tools.
- Collaborated with developers to improve functionality and user experience.

---

## 🤖 Automation Testing

- Developed automated test scripts using:
  - Java  
  - Selenium WebDriver  
  - TestNG  
  - Page Object Model (POM)  
- Ensured clean and maintainable code through modular test architecture.
- Used Git & GitHub for version control and team collaboration.

---

## 🧑‍💼 My Role as Team Lead

- Led sprint planning meetings and daily stand-ups.
- Assigned testing tasks and ensured timely completion.
- Provided support and mentorship to team members when needed.
- Promoted transparency and continuous improvement within the QA cycle.
